# BLACK BLADE — Barber Website

A black-and-white, responsive barber/salon website built with plain HTML, CSS and JavaScript.

## Included
- Responsive 2026-style visual design
- Hero section with animated loader
- Services
- Pricing
- Gallery
- About / brand section
- 3D-style animated Black Blade mark using CSS
- WhatsApp booking CTA
- Contact section
- Scroll reveal animations
- Mobile navigation

## IMPORTANT: Customize before launch
1. Open `index.html`.
2. Change the demo phone number `+94 77 000 0000` and WhatsApp number in `script.js`.
3. Change address and opening hours.
4. Replace the demo prices/services with your real menu.
5. Replace the Unsplash image URLs with your own licensed salon images if desired.

## Run
Double-click `index.html` or open it in any modern browser.

No framework or build step is required.
